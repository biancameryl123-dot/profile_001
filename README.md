# Bianca Velmayil - Interactive 3D Digital Media & Animation Portfolio

A high-performance, interactive 3D Web Portfolio website created for **Bianca Velmayil** (Digital Media & Animation student at St. Joseph's University, Bengaluru).

## Features
- **Interactive 3D Background Character**: Stylized Three.js 3D character avatar that tracks mouse movements (head/eyes/body) and responds to clicks with arm waving, facial expressions, speech bubbles, and particle bursts.
- **Glassmorphism UI**: Modern cyberpunk aesthetic with cyan & magenta neon accents, responsive glass panels, and interactive filters.
- **Complete Resume Sections**:
  - Hero Section with summary & location
  - About Me & Highlights
  - Interactive Project Showcase (Graphic Novel, 3D Modeling, Short Film, AR/VR) with category filter & detailed modals
  - Skills Matrix (Digital Media, Creative, Soft Skills)
  - Education Timeline & Hobbies (Drawing, Singing, Video Editing)
  - Interactive Contact Form & Footer

## How to Host on GitHub Pages
1. Extract this ZIP archive into a folder on your computer.
2. Push all the files (`index.html`, `style.css`, `script.js`, `README.md`) to a repository on **GitHub**.
3. Go to your repository settings on GitHub:
   - Navigate to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, select `Deploy from a branch`.
   - Select `main` (or `master`) branch and click **Save**.
4. Your website will be live at `https://<your-username>.github.io/<your-repo-name>/`!
